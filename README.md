# Yaqeen Store

يقين ستور - Premium e-commerce platform for SPC flooring, stone alternatives & soft stones.

## Features

- **Production-ready** Next.js 15 e-commerce store
- **RTL** Arabic-first with ILS (₪) currency
- **Premium luxury** design system
- **AI Shopping Assistant** with secure backend API routes
- Fully responsive, SEO-friendly, accessible
- Built-in Admin Dashboard

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env.local` and configure:

- `AI_PROVIDER` - AI provider (openai, anthropic, etc.)
- `AI_MODEL` - Model name
- `AI_API_KEY` - API key (server-side only)
- `AI_ENABLED` - Enable/disable AI features

## Build

```bash
npm run build
npm run start
```
